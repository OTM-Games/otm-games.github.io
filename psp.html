Controls

  • D-pad arrow keys · Start Enter
  • See or change every key in the game's bottom menu → Control Settings
  • A controller works too: plug it in and press a button

Make it run faster

  • Start on Balanced. If it still lags, try Speed, then Turbo
  • Plug in your charger: laptops and Chromebooks slow down on battery
  • Close other tabs, and keep this tab in front
  • Lighter games (Patapon, LocoRoco, Lumines) run much better than big 3D ones (God of War, GTA)

Saves

  • Save in the game like normal. Saves stay in this browser on this site
  • For a backup, use Export Save File in the game's bottom menu
  • Clearing your browser data deletes saves
